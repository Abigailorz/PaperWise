# PaperWise 逐文件解读

本文按目录逐个说明每个文件的作用、关键内容与在系统中的角色。可与 [项目全景解析.md](./项目全景解析.md) 对照阅读。

## 顶层（src/paperwise/ 根）

| 文件 | 作用 |
|------|------|
| `__init__.py` | 包标记 |
| `recommender.py` | 主动论文推荐。`extract_paper_topics` 从论文提取主题、`remember_paper` 写论文兴趣信号、`build_interest_profile` 聚合「声明/论文/对话」三类信号、`score_paper` 相关度评分、`recommend` 走 arXiv→列表页→Semantic Scholar 三级检索。 |
| `evolution.py` | 持续进化闭环。`EvolutionEngine` 把失败轨迹聚合为模式，按「知识→指令→程序→参数」四层固化；`TrajectoryRecord` 记录运行轨迹。 |

## core/ — 核心引擎

| 文件 | 作用 |
|------|------|
| `agent.py` | 增强 ReAct 循环。`Agent.run()` 是主入口，实现 pre_llm→call_llm→post_llm→解析响应→post_tool→check_exit 的迭代；含 Budget-Aware、Plan-then-Execute、过早终止检测（Proposer-Reviewer）、流式思考、7 种退出条件、轨迹持久化。 |
| `session.py` | 对话式会话 `AgentSession`。与 Agent 区别是跨轮保留上下文；负责记忆注入、上传论文处理、后台索引（KB/RAPTOR/GraphRAG）、论文兴趣信号写入、持久化与恢复。 |
| `llm_client.py` | 多提供商 LLM 客户端 `LLMClient`（DeepSeek/Moonshot/OpenAI/兼容端点），支持非流式 `chat` 与流式 `chat_stream`（含 reasoning、tool_calls 增量解析），`count_tokens` 估算。 |
| `scheduler.py` | 主动调度器 `Scheduler`（单例）。`add_timer`/`add_monitor` 注册定时/监控事件，到期触发回调注入会话。 |
| `bus.py` | Agent 消息总线 `AgentBus`（邮箱模型）。`register` 建邮箱、`send` 投递、`receive` 读取，用于多 Agent 消息通信。 |
| `types.py` | 全部数据类：`Role`、`ToolRisk`、`ToolCall`、`ToolResult`、`Message`、`AgentState`、`AgentConfig`、`AgentResult`、`ParsedPaper`。 |
| `__init__.py` | 导出 `get_agent`（延迟导入避免循环依赖）。 |

## harness/ — Harness 护栏工程

| 文件 | 作用 |
|------|------|
| `harness.py` | Harness 编排器。pre_llm/post_llm/pre_tool/post_tool 钩子、token 追踪、熔断器、退出条件检查、瞬时消息清理。 |
| `context.py` | `ContextManager` 上下文管理，实现 5 层压缩：工具输出截断→噪声删除→微压缩→归档摘要→LLM 全量压缩，以及初始上下文构造。 |
| `constraints.py` | `ConstraintEngine` 约束引擎，输入/执行/输出三层护栏，含路径白名单与沙箱策略。 |
| `security.py` | 安全规则（共享单一真相源）：`check_command_dangerous`/`check_path_dangerous`/`check_injection`/`check_api_key_leak`/`check_system_prompt_leak`，含工具风险等级与调用次数限制。 |
| `sidecar.py` | `InjectionSidecar` 注入审查：用 LLM 审查论文内容是否含操控指令，把论文当数据而非指令。 |
| `status_bar.py` | `StatusBar` 状态栏：自动 TODO 推断、工具使用统计、循环检测。 |
| `correction.py` | `Corrector` 纠正器：重试判断、指数退避、错误记录与熔断器。 |
| `verification.py` | `OutputVerifier` 输出验证：文件存在、内容长度、JSON 合法、报告结构完整性。 |
| `__init__.py` | 包标记。 |

## tools/ — 工具系统

| 文件 | 作用 |
|------|------|
| `base.py` | `BaseTool` 工具基类 + `ToolDefinition` + `AccessRequested`；实现参数校验与分级路径沙箱（`_resolve_path`）。 |
| `registry.py` | `ToolRegistry` 工具注册中心：注册/查找/导出 OpenAI function-calling 定义、渐进式披露、`create_default` 工厂。 |
| `file_tools.py` | 文件工具：`ReadFileTool`（带行号）、`WriteFileTool`（含文件锁）、`EditFileTool`（精确替换）。 |
| `search_tools.py` | 检索工具：`GrepTool`（内容搜索）、`GlobTool`（文件名搜索）。 |
| `exec_tools.py` | 执行工具：`CodeInterpreterTool`（Python 执行）、`BashTool`（命令执行），含 Windows 命令适配。 |
| `skill_tools.py` | Skill 工具：`SkillListTool`、`SkillLoadTool`、`DiscoverTool`（动态工具发现）。 |
| `collab_tools.py` | 协作工具：`SpawnSubAgentTool`、`SendMessageTool`、`ReceiveMessageTool`、`SetTimerTool`、`MonitorShellTool`、`AskUserTool`、`NotifyUserTool`。 |
| `access_tool.py` | `RequestFileAccessTool` 文件访问申请：读→加白名单，写→拷贝到沙箱。 |
| `locks.py` | `FileLockManager` 文件锁，防止多 Agent 同时写同一文件。 |
| `__init__.py` | 导出 `get_registry`。 |

## memory/ — 记忆与知识库

| 文件 | 作用 |
|------|------|
| `user_memory.py` | `UserMemory` 用户记忆（Advanced JSON Cards，5 类）；`MemoryCard` 卡片；LLM 从对话提取记忆、去重合并（同名且同值）、冲突检测、周期整合、注入上下文。 |
| `knowledge_base.py` | `KnowledgeBase` 完整 RAG：Dense/Sparse/Hybrid(RRF)/Rerank/HyDE/RAPTOR/GraphRAG/多模态；`DenseRetriever`/`SparseRetriever`/`HybridRetriever` 三检索器。 |
| `storage.py` | 存储后端：`SQLiteBackend`、`JSONFileBackend`、`create_storage` 工厂，含旧 JSON 自动迁移。 |
| `__init__.py` | 包标记。 |

## parsers/ — 解析

| 文件 | 作用 |
|------|------|
| `pdf_parser.py` | `PDFParser` PDF 解析编排：文本/章节结构、图表、表格、公式、元数据、参考文献，输出到 `workspace/{paper_id}/`。 |
| `arxiv.py` | arXiv 工具：`extract_arxiv_id`（URL/裸 ID）、`download_arxiv_pdf`（多源回退下载）。 |
| `__init__.py` | 包标记。 |

## generators/ — 生成

| 文件 | 作用 |
|------|------|
| `report.py` | `ReportGenerator` 报告生成：报告系统提示词、任务模板、`assemble`（确定性拼装 report.md）。 |
| `pptx.py` | `PPTXGenerator` PPT 生成（标题/章节/批判/图表/表格/致谢等幻灯片）+ PPT 系统提示词。 |
| `__init__.py` | 导出 `ReportGenerator`。 |

## agents/ — 多 Agent 编排

| 文件 | 作用 |
|------|------|
| `orchestrator.py` | `AgentOrchestrator`（Manager+Worker，不共享上下文）+ `PaperAnalysisPipeline`（5 类子 Agent 规格）+ `run_paper_analysis`（revise-until-pass 闭环）+ `parse_findings`。 |
| `paper_analyst.py` | `PaperAnalystConfig` 分析 Agent 的系统提示词与任务模板。 |
| `__init__.py` | 包标记。 |

## evaluation/ — 评估

| `benchmark.py` | `PassKEvaluator`（Pass@k/Pass^k）+ `AblationTester`（逐组件消融）。 |
