# P4.5 — Retrieval-native Paper Agent

## Goal

Replace "read the whole paper into context" with task-directed evidence
retrieval. P4.5 makes evidence a first-class DAG capability instead of another
optional tool.

## Pipeline

```text
Paper
  -> Section-aware Parser
  -> Dense + BM25 Hybrid Retrieval (RRF)
  -> Optional Cross-Encoder / LLM Reranker
  -> Evidence Pack
  -> Reasoning / Verification
  -> Citation Grounding Audit
```

## Core objects

- `EvidenceSnippet`: section, figure, table, equation, or reference with
  stable paper id, location, and citation.
- `EvidencePack`: a bounded, serialized set of snippets for one reasoning task.
- `EvidenceRetriever`: indexes the current paper and searches the user's
  cross-paper library.
- `CitationGroundingAuditor`: measures citation coverage and evidence coverage.

## Dynamic DAG integration

The complex paper path now runs:

```text
read_paper -> retrieve_evidence -> analyze_method -> generate_report -> review
```

`retrieve_evidence` writes `evidence/evidence_pack.json` and records an
`evidence_pack` trace event. Empty retrieval raises so the existing replanner
can recover instead of letting a writer hallucinate.

## Acceptance

- Section-aware chunks preserve stable one-based source line numbers.
- Current-paper and library scopes both return citable snippets.
- Figure/table/equation/reference artifacts are retrievable.
- Empty or out-of-domain retrieval is marked `low_recall` or triggers replanning.
- P4.5 unit and grounding tests pass.
