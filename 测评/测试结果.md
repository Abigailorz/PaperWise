## 四、关键发现（诚实版）

1. **报告生成是最不稳定的短板**：
   - 本次 3DGS 报告生成失败（45 步触顶、未产出 report.md）；
   - 上一次完整运行时 Feature 3DGS 报告生成失败、3DGS 通过；
   - 两次结果对调，说明这是 **LLM 随机性 + 长文步骤预算** 的共同问题，单靠调大步骤数不能稳定解决。

2. **幻觉检测器不稳定（同源 Judge）**：
   - `critical`、`error`、`major` 散落出现，且 `error` 表示检测器自身调用失败；
   - 这与主模型同为 DeepSeek 有关，结果只能作为参考信号。

3. **报告生成的工具合法率偏低**（61%–63%）：Agent 在写长报告时频繁触发工具报错/拦截，效率偏低。

4. **核心能力达标**：信息抽取、数值核验、方法核验、幻觉否决（拒绝编造）在三篇论文上均稳定通过，说明“找得到、抄得对、不瞎编”的基础能力是可靠的。

## 五、结论

- PaperWise Agent 的**事实抽取与安全合规能力是扎实的**（Part A 100%，Part B 基础场景稳定通过）。
- 最大短板是**长论文的报告生成**，需要从“靠 Agent 在步骤预算内硬写”改为**更确定性的报告生成流程**（例如：先由分析 Agent 写章节，再由专门的报告组装器机械拼接），而不是继续调大步骤数。
- 幻觉/Rubric 等 LLM 指标应改用**异源 Judge** 或补充**确定性事实校验**。
