# 消融实验是否合理？（面向非 LLM 专家的分析）

## 一、先解释：什么是“消融”

“消融实验（Ablation Study）”这个词来自生物/医学的“切除某部分看会发生什么”。在机器学习里，它指的是：

> 把一个系统里的**某个组件拿掉**，看性能掉多少，从而证明这个组件**确实有用**。

比如一个图像分类模型里有「数据增强」「注意力模块」「残差连接」三个组件。消融就是：

- 完整模型：准确率 92%
- 去掉数据增强：88%
- 去掉注意力模块：81%
- 去掉残差连接：75%

结论：残差连接贡献最大（去掉后掉得最多）。

## 二、在 LLM Agent 上做消融：合理，但要换个思路

**结论：合理，而且值得做**。它能回答你最关心的一个问题——“我加的这些功能（记忆、安全层、多 Agent 协作）到底有没有用，还是只是花架子？”

但要注意：**LLM Agent 和传统机器学习模型有本质区别**，所以“消融”的做法不能照搬。

### 关键区别：确定性 vs 随机性

- 传统 ML 模型：同一个输入，输出基本稳定（训练好后是确定的数学函数）。所以**跑一次**就能看出差异。
- LLM Agent：同一个问题问两次，答案可能不同（模型采样有随机性）。所以**单次结果不能下结论**，需要多次重复取平均。

这意味着：LLM 的消融如果只跑 1 次，你看到“去掉记忆后分数掉了 10 分”，很可能只是**随机波动**，不是记忆真的有用。

### 关键区别：消融 ≠ 严格因果

传统 ML 里“拿掉一个组件”是干净的（模型结构明确）。但 LLM Agent 里，“记忆”不是独立的开关，而是**以文字形式注入到提示词里**的。拿掉记忆 = 改提示词，而 LLM 对提示词非常敏感，会引发连锁反应（比如它没看到用户背景，就换了回答策略）。

所以更准确的说法是：消融证明的是“**这个组件在当前提示词/流程下的贡献**”，而不是“这个组件从物理上绝对必要”。

## 三、PaperWise 里哪些组件值得消融

按“价值/成本比”排序：

| 组件 | 消融方式 | 期望证明什么 | 难度 |
|------|---------|-------------|------|
| **Harness 安全层** | 开/关安全校验 | 安全层是否真的拦得住注入、危险命令 | 低（确定性、便宜） |
| **记忆/知识库（Memory+KB/RAG）** | 注入/不注入记忆上下文 | 记忆是否真的让回答更相关、推荐更准 | 中（需要 LLM 跑多次） |
| **多 Agent 编排** | 单 Agent vs 编排管道 | 拆分协作是否真的比一个 Agent 强 | 中 |
| **工具集** | 有无 code_interpreter 等 | 工具是否真的提升了能力 | 中 |
| **模型选择** | DeepSeek vs 其他 | 换模型是否提升（这更像“对比”而非“消融”） | 低（但只是横向对比） |

## 四、严谨消融的三个铁律

如果要做，请遵守：

1. **一次只动一个变量**：如果同时“去掉记忆 + 换模型”，性能变了，你无法归因到谁。
2. **每个条件跑 k≥3–5 次取平均**：否则随机噪声会淹没真实差异。
3. **优先用确定性指标，LLM 指标要打折**：
   - 确定性指标（工具合法率、是否命中金标关键词、是否写出文件）**可靠**。
   - LLM-as-a-Judge 的 Rubric/幻觉评分，因为 Judge 和主模型同源，**只能当辅助信号**。

## 五、我个人的建议

对你（以及对一个正在打磨的 Agent 产品）来说，消融最有价值、也最容易做的是这两个：

### 建议 1：先做“Harness 安全层”消融（便宜、确定、最有说服力）

- 对比：开安全层 vs 关安全层，喂同一批攻击样本（注入、危险命令、路径越权）。
- 指标：被拦截的比例。
- 因为这是**确定性逻辑**，跑一次就够，结果干净，能直接证明“安全层不是摆设”。

### 建议 2：再做“记忆/知识库”消融（稍贵，但最能证明核心卖点）

- 对比：注入记忆 vs 不注入记忆，跑同一批“与用户研究兴趣相关”的问答/推荐任务。
- 指标：相关度命中、推荐是否命中用户方向、用户偏好是否被遵守。
- 需要 k≥3–5 次，控制提示词除记忆外完全一致。

### 暂缓：多 Agent 编排、工具集消融

这两个更复杂、更贵、结论也更模糊，建议等前两个做完、系统稳定后再考虑。

## 六、一句话总结

**消融是合理的，也是证明“组件有价值”的最直接方式；但对 LLM 系统，它证明的是“贡献”而非“绝对因果”，且必须用“多次重复 + 一次一个变量 + 优先确定性指标”来做，否则结论不可信。** 建议从最便宜最确定的「安全层消融」开始，再做最有产品价值的「记忆消融」。
