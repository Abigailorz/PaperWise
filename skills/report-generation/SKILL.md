# Report Generation Workflow

## Structure
Standard deep reading report has 7 sections:
1. Overview, 2. Motivation, 3. Methodology, 4. Experiments,
5. Critical Analysis, 6. Related Work, 7. Conclusion

## Citation Rules
- Every factual claim MUST cite source (section/line)
- Figures: "Figure 3 shows..." (with description)
- Tables: "Table 1 reports..." (with key numbers)
- Equations: reference by number, include LaTeX when helpful

## Formatting Standards
- Use proper Markdown headings (## for sections, ### for subsections)
- Use **bold** for key terms on first use
- Use `code` for method names, variable names
- Use blockquotes for direct quotes from the paper
- Include a Table of Contents at the top
